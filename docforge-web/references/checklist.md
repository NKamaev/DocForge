# Чек-лист самопроверки DocForge (shadcn/ui + Tailwind)

Проходи список сверху вниз. P0 должны пройти ДО генерации артефакта.

---

## P0 — Блокирующие (обязательно)

- [ ] **Брендовый индиго** (`oklch(0.55 0.16 232)`) используется **максимум 2 раза**
      на экран (кнопка CTA + заголовок раздела/eyebrow).
      Никаких других ярких акцентов.
- [ ] **Шрифт документа** — serif (`font-display` → Source Serif 4) в превью и редакторе.
      Шрифт интерфейса — sans (`font-ui` → Inter Tight).
      Моноширинный — только для имен параметров `{{param}}` (`font-mono`).
- [ ] **Все изображения** — только заглушки (серый фон + текст "Изображение").
      Никаких внешних ссылок на стоковые фото.
- [ ] **Мобильная версия** — при 920px сайдбар скрывается (`hidden !important`),
      сплит-лейаут переходит в одну колонку, таблицы получают горизонтальный скролл.
- [ ] **`data-od-id`** присутствует на каждом `<section>` и основных блоках
      (topbar, sidebar, content, editor-toolbar, tiptap-editor, param-panel).
- [ ] **Токены Tailwind** — все цвета ссылаются на `text-ink-*`, `bg-surface`, `border-border`, `bg-brand`.
      Никаких хардкодных hex-кодов или oklch-значений в классах.
- [ ] **Tailwind CDN** — подключен через `<script src="https://cdn.tailwindcss.com">`
      с правильным конфигом `tailwind.config` для oklch-переменных.

---

## P1 — Должны пройти

- [ ] **Dark mode** (`[data-theme="dark"]`) инвертирует цвета поверхностей.
      Проверяется через DevTools → force attribute.
- [ ] **Статусные бейджи** правильно окрашены:
      - Черновик → нейтральный (ink-3)
      - Сформирован / Опубликован → зеленый `oklch(0.50 0.16 160)`
      - Экспортирован → бренд индиго
- [ ] **Русский язык UI** — все навигационные элементы, кнопки и заголовки
      на русском (Главная, Документы, Шаблоны, Справочники и т.д.).
- [ ] **Параметры `{{param}}`** выделены `font-mono`, цветом `text-brand` и `text-xs`
      внутри редактора TipTap.
- [ ] **Ховер-эффекты** — строки таблиц, кнопки и элементы сайдбара имеют
      `hover:bg-brand-soft` и `transition-colors`.

---

## P2 — Приятные мелочи

- [ ] **Тени** — карточки используют `shadow-sm`, попапы/модалки — `shadow-lg`.
- [ ] **Радиусы** — кнопки и инпуты `rounded-md` (6px), карточки — `rounded-lg` (8px).
- [ ] **Drag-and-drop** — визуальная обратная связь при перетаскивании
      документов (opacity-50 или dashed border).
- [ ] **Курсоры коллаборации** — заглушки цветных индикаторов других пользователей
      в редакторе (цветные линии с инициалами).

---

## 5-мерная самокритика (выполни перед эмиссией артефакта)

1. **Философия (1-10):** Насколько это "чувствуется" как рабочий инструмент
   для юристов? Профессионально, минималистично, без украшательств?
2. **Иерархия (1-10):** Визуальная структура ясна? Заголовки → списки → действия?
   Бренд индиго ведет глаз только к первичным CTA?
3. **Детали (1-10):** Отступы ровные? TipTap редактор выглядит как настоящий
   документ (serif, отступы, иерархия заголовков)?
4. **Функция (1-10):** Пользователь понимает, куда нажимать, чтобы создать
   документ? Форма анкеты понятна? Таблицы читаемы?
5. **Инновации (1-10):** Как параметры `{{param}}` визуально отличаются от
   обычного текста? Есть ли визуальные подсказки для совместного редактирования?
