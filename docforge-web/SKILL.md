# DocForge — Конструктор документов (shadcn/ui + Tailwind)

Создай интерфейс модульного монолита для управления документами.
Цель: SaaS-решение для юристов, HR и финансовых отделов.

## Контекст продукта

DocForge — это система, где встречаются шаблоны и реальные документы.
Бэкенд: Spring Boot 3.3 (Java 21). Фронтенд: React 18 + TypeScript.

### Основные сценарии
1. **Дизайнер шаблонов** — визуальный редактор с параметрами `{{param}}`,
   условиями `{{#if}}` и вариантами формулировок.
2. **Заполнение анкеты** — ответы на вопросы автоматически подставляются в шаблон.
3. **Совместная работа** — TipTap 2 + Y.js, отображение курсоров других пользователей.
4. **Управление файлами** — дерево папок, drag-and-drop, статусы документа.

## Дизайн-система (Токены)

Используй **только** эти значения. Не придумывай новые цвета.

### Цвета (oklch)
```css
:root {
  --brand: oklch(0.55 0.16 232);      /* Основной индиго */
  --brand-soft: oklch(0.96 0.03 232); /* Фон акцента */

  --ink-1: oklch(0.15 0.02 280);      /* Заголовки */
  --ink-2: oklch(0.30 0.02 280);      /* Основной текст */
  --ink-3: oklch(0.45 0.02 280);      /* Вторичный текст */
  --ink-4: oklch(0.60 0.02 280);      /* Заглушки */

  --bg: oklch(0.98 0.005 280);        /* Фон страницы */
  --surface: oklch(1 0 0);             /* Поверхности (карточки) */
  --border: oklch(0.90 0.01 280);     /* Границы */
}
```
*Dark mode:* инвертируй `--ink-*` и `--bg`/`--surface`.

### Типографика
- **UI:** "Inter Tight" (шрифт интерфейса).
- **Документ:** "Source Serif 4" (шрифт для превью и редактора).
- **Моно:** "JetBrains Mono" (для кода и параметров `{{...}}`).

## Инструкция для агента

### Шаг 0 — Подготовка
1. **Прочти `assets/template.html`**. Там подключены Tailwind (через CDN) и
   базовые стили shadcn. Все цвета должны ссылаться на CSS-переменные через
   `tailwind.config.theme.extend.colors`.
2. **Прочти `references/layouts.md`**. Там макеты для Home, Documents, Templates,
   Editor и Questionnaire.
3. **Прочти `references/components.md`**. Там примеры использования кнопок,
   таблиц, бейджей и диалогов shadcn/ui.

### Шаг 1 — Создание проекта
Скопируй `assets/template.html` в корень проекта как `index.html`.
Убедись, что в `<head>` подключены:
- Google Fonts (Inter Tight, Source Serif 4, JetBrains Mono).
- Tailwind CDN скрипт с правильным конфигом для oklch.

### Шаг 2 — Сборка страниц
Используй классы Tailwind (`bg-background`, `text-foreground`, `border`, `rounded-lg`).
Не используй кастомные CSS-классы, если хватает утилит Tailwind.

Приоритет страниц (сообщи пользователю перед началом):
1. **Главная** — карточки статистики, список "Продолжить работу".
2. **Мои документы** — дерево папок + таблица документов.
3. **Конструктор шаблона** — тулбар + редактор + панель параметров.
4. **Заполнение** — сплит-лейаут (анкета слева, превью справа).

### Шаг 3 — shadcn/ui компоненты
Используй компоненты через глобальный объект `window.shadcn` (если доступен в превью)
или пиши разметку, максимально приближенную к стилю shadcn:
- Кнопки: `bg-primary text-primary-foreground rounded-md px-4 py-2`
- Таблицы: `w-full caption-bottom text-sm` + границы
- Бейджи: `inline-flex items-center rounded-full border px-2.5 py-0.5 text-xs font-semibold`

### Шаг 4 — Самопроверка
Пройди `references/checklist.md`. P0 обязательны к выполнению.

## Жесткие правила
- **Акцентный цвет (brand indigo)** — используй не более 2 раз на экране
  (кнопка CTA и заголовок раздела).
- **Шрифт документа** — только serif (Source Serif 4).
- **Изображения** — только заглушки (фон серый, текст "Изображение").
- **Tailwind + shadcn** — не подключай Ant Design. Используй утилиты Tailwind.
- **Мобильная версия** — при 920px сайдбар скрывается, таблицы становятся скроллящимися.
- **Русский язык** — все надписи в интерфейсе на русском.
