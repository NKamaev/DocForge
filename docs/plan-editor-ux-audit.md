# План аудита и исправления UX редактора шаблонов

> Статус: готов к реализации  
> Приоритет проблем: критический → высокий → средний

---

## 1. Выявленные проблемы

### 1.1 Дублирующиеся и неинформативные иконки

| Иконка | Где используется | Проблема |
|--------|-----------------|---------|
| `OrderedListOutlined` | "Нумерованный список" (Toolbar), "Нумерованный пункт" (FloatingInsertMenu), кнопка "Пункт" (Toolbar) | Три разные функции — одна иконка |
| `LinkOutlined` | "Вставить ссылку" и "Ссылка на пункт" | Разные концепции, неотличимы визуально |
| `MinusOutlined` / `LineOutlined` | Горизонтальная линия / Разрыв страницы | Иконки слишком похожи |
| `MenuOutlined` | "По ширине" (выравнивание) | Ассоциируется с "меню", а не с justify |
| Стрелки `→ ↓ ← ↑` | Ориентация текста в ячейке | Стрелки показывают направление, а не поворот |

**Файлы:** `EditorToolbar.tsx:447-451`, `FloatingInsertMenu.tsx:87-93`, `TableBubbleMenu.tsx:163-190`

---

### 1.2 Перегруженный и неудобно расположенный тулбар

**EditorToolbar.tsx** — одна длинная строка с `flexWrap: 'wrap'`, 8 визуальных групп без заголовков:

1. Шрифты (Select×3) — хорошо
2. Форматирование (Б/К/Ч/З/верх/низ) — хорошо
3. Цвета — хорошо
4. Заголовки — хорошо
5. Выравнивание — хорошо
6. Отступы `→|` / `|←` — нечитаемые символы
7. Списки — хорошо
8. Вставка (таблица/линия/разрыв/изображение/ссылка) — хорошо
9. Специфика шаблона (Параметр/Условие/Пункт/Ус.текст/Ссылка на пункт) — **сокращение "Ус.текст" непонятно**

**Проблемы:**
- При узком экране строка переносится — теряется логика группировки
- "Ус.текст" — нечитаемое сокращение
- Кнопки "Ссылка" (toolbar) и "Ссылка на пункт" визуально неотличимы

---

### 1.3 Некорректная работа панели таблицы (TableBubbleMenu)

**Корень проблемы — несогласованная модель применения изменений:**

| Контрол | Применяется | Требует "Применить"? |
|---------|-------------|---------------------|
| Вертикальное выравнивание | Немедленно (`onClick → setCellAttribute`) | Нет |
| Ориентация текста | Немедленно | Нет |
| Фон ячейки | Немедленно (`onChange`) | Нет |
| Размер (ширина/высота) | Немедленно (`onChange`) | Нет |
| Ручная настройка границ (стиль+ширина+цвет+стороны) | **Только по кнопке "Применить"** | **Да** |

Пользователь не понимает, почему одни изменения видны сразу, а для границ нужна отдельная кнопка. Это нарушение принципа единообразия (principle of least astonishment).

**Дополнительные проблемы TableBubbleMenu:**
- Панель слишком длинная — на стандартном экране уходит за правый край
- Нет визуального превью выбранных сторон границы (только текстовые кнопки Верх/Право/Низ/Лево)
- `ColorPicker` для фона применяет цвет на каждый пиксель перетаскивания — лишние транзакции в TipTap
- Пресет "Все" границ не показывает текущее состояние границ ячейки

## 2. План исправлений

### Этап 1 — Критические: устранение путаницы с "Применить" (TableBubbleMenu)

**Задача:** Унифицировать модель — либо всё немедленно, либо всё через "Применить".

**Решение: убрать кнопку "Применить", сделать границы мгновенными.**

Изменить логику в `TableBubbleMenu.tsx`:
- Удалить кнопку "Применить" (`applyBorders`)
- Навесить `onChange` на `Select` стиля, `InputNumber` ширины, `ColorPicker` цвета — и сразу применять
- Стороны (Верх/Право/Низ/Лево) по клику мгновенно применять с текущими параметрами

```
Было: выбрать стиль → выбрать ширину → выбрать цвет → выбрать стороны → [Применить]
Станет: выбрать стиль → выбрать ширину → выбрать цвет → кликнуть нужную сторону → мгновенно
```

**Файл:** `frontend/src/components/template-designer/TableBubbleMenu.tsx:237-281`

### Этап 2 — Высокий: замена дублирующихся иконок

**Файл:** `EditorToolbar.tsx`, `FloatingInsertMenu.tsx`

#### 2.1 Нумерованный пункт vs Нумерованный список

| Функция | Текущая иконка | Заменить на |
|---------|---------------|-------------|
| Нумерованный список | `OrderedListOutlined` | оставить |
| Нумерованный пункт (Clause) | `OrderedListOutlined` с цветом | `NumberOutlined` (§ или #) |
| Кнопка "Пункт" в toolbar | `OrderedListOutlined` | `NumberOutlined` |

#### 2.2 Ссылка vs Ссылка на пункт

| Функция | Текущая иконка | Заменить на |
|---------|---------------|-------------|
| Гиперссылка | `LinkOutlined` | оставить |
| Ссылка на нумерованный пункт | `LinkOutlined` | `ApartmentOutlined` или `NodeIndexOutlined` |

#### 2.3 Горизонтальная линия vs Разрыв страницы

| Функция | Текущая иконка | Заменить на |
|---------|---------------|-------------|
| Горизонтальная линия | `MinusOutlined` | `LineOutlined` (уже есть, поменять местами логически) |
| Разрыв страницы | `LineOutlined` | `ScissorOutlined` или `SwitcherOutlined` |

#### 2.4 Выравнивание по ширине

| Функция | Текущая иконка | Заменить на |
|---------|---------------|-------------|
| Justify | `MenuOutlined` | `MenuUnfoldOutlined` или inline-символ `≡` с пробелами |

#### 2.5 Ориентация текста в ячейке

Заменить `→ ↓ ← ↑` на текстовые метки или символы, отражающие поворот:
- Горизонтально: `A` (обычный текст)
- 90°: `A` с поворотом через CSS или `↺`
- Использовать `Tooltip` с чётким описанием "Текст вертикально (90°)"

### Этап 3 — Высокий: улучшение читаемости тулбара

**Файл:** `EditorToolbar.tsx`

#### 3.1 Исправить нечитаемые метки
- `"Ус.текст"` → `"Условный текст"` (кнопка чуть шире — норм)
- `"→|"` / `"|←"` → использовать `IndentOutlined` / `VerticalLeftOutlined` из @ant-design/icons

#### 3.2 Добавить Tooltip к кнопкам без них
Убедиться что все кнопки имеют Tooltip (сейчас не хватает у indent-кнопок и некоторых других)

#### 3.3 Разделить template-специфичную секцию
Добавить лёгкий фоновый цвет (`background: #f0f5ff`) к блоку "Параметр / Условие / Пункт / ..." чтобы визуально отделить от стандартного форматирования.

---

### Этап 4 — Средний: рефакторинг TableBubbleMenu под компактный layout

**Проблема:** панель не помещается на экране.

**Решение:** разбить на две строки или использовать Popover для настройки границ.

```
Строка 1: [Строки: ↑+ ↓+ ✕] | [Колонки: ←+ →+ ✕] | [Объед. | Разбить] | [Верт. выравн.] | [Удалить таблицу]
Строка 2 (только если активна): [Граница: стиль | ширина | цвет | Верх Право Низ Лево] | [Фон: цвет | ✕] | [Ориент.]
```

Либо кнопка "Границы..." открывает Ant Design `Popover` с настройками.

---

### Этап 5 — Средний: FloatingInsertMenu

**Файл:** `FloatingInsertMenu.tsx:86-93`

**Проблема:** "Нумерованный список" и "Нумерованный пункт" — одна иконка с разным цветом.

**Решение:** применить те же иконки что выбраны в Этапе 2 — `OrderedListOutlined` для списка, `NumberOutlined` для пункта.
