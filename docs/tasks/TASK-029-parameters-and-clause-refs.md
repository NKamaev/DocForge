## Интерпретация

Пользователь хочет в тексте шаблона/документа иметь возможность:

1. **Параметры** — вставлять inline-плейсхолдеры для полей шаблона (например, `{{field_name}}`), которые при заполнении документа заменяются на реальные значения. Параметры берутся из существующих полей шаблона (template fields).

2. **Ссылки на пункты** — вставлять cross-reference на пронумерованный пункт документа (например, «п. 2.3», «§ 1»). Номер обновляется автоматически при перестановке блоков.

Оба типа — это кастомные TipTap inline-узлы в редакторе. На бэкенде нужна поддержка хранения этих узлов в JSON и их резолвинг при экспорте (DOCX/PDF).
