## Интерпретация

В интерфейсе истории редакций добавить возможность просмотра изменений (diff) между выбранной редакцией и текущим состоянием (или предыдущей редакцией). Изменения отображаются прямо в тексте: удалённые фрагменты — зачёркнутым красным текстом, добавленные — подчёркнутым зелёным.

Режим просмотра diff — только для чтения, не позволяет редактировать документ.

## Поэтапное исполнение

1. **Добавить API-функцию** `getRevisionDiff(documentId, revisionId, compareTo?)` в `documents.ts`.
2. **Добавить типы** `DiffChunk { type: 'INSERT' | 'DELETE' | 'EQUAL'; text: string }` и `RevisionDiffResponse` в `types/`.
3. **Создать компонент `DiffViewer`** — принимает `chunks: DiffChunk[]`, рендерит их как параграф текста:
   - `EQUAL` — обычный текст
   - `INSERT` — `<ins>` с зелёным фоном
   - `DELETE` — `<del>` с красным фоном и зачёркиванием
4. **В drawer истории редакций** (`QuestionnairePage.tsx`) добавить к каждой редакции кнопку «Изменения» (или иконку `DiffOutlined`):
   - При клике: загружает diff через API, показывает `DiffViewer` в модальном окне или в дополнительной панели.
5. **Кнопка-переключатель** в основном интерфейсе (опционально): «Показать изменения последней редакции» — если включена, `DiffViewer` отображается под редактором.
6. **Режим только чтения**: пока виден diff — редактор заблокирован.
