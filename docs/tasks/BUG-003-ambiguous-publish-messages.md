## Постановка задачи (от пользователя)

```
При публикации/снятия с публикации шаблона возникаються не совсем корректные
сообщения, которые можно по разному понять.
```

---

## Интерпретация

Сообщения в нескольких местах интерфейса при публикации/снятии шаблона сформулированы
двусмысленно: непонятно — это описание текущего состояния или только что выполненного
действия. Нужно привести все тексты к единому, однозначному стилю «глагол-действие».

**Места, требующие исправления:**

| Место | Текущий текст | Проблема |
|---|---|---|
| `TemplateList.tsx:48` | `'Шаблон снят с публикации'` | Норм, но посмотреть в контексте |
| `TemplateList.tsx:51` | `'Шаблон опубликован'` | Двусмысленно: состояние или действие? |
| `TemplateList.tsx:55` | `'Не удалось изменить статус публикации'` | Слишком технически, непонятно что делать |
| `TemplateList.tsx:114` | `okText: 'Снять'` | Обрезанный текст кнопки — «снять» что? |
| `TemplateDesigner.tsx:335` | `'Шаблон снят с публикации'` / `'Шаблон опубликован'` | Те же двусмысленности |
| `PublishedBanner.tsx:10` | `'Шаблон опубликован — редактирование недоступно'` | Первая часть — состояние, вторая — ограничение; формула нелогична |

**Ожидаемый результат:** все уведомления и баннер используют активный залог
(«Шаблон опубликован» → «Шаблон успешно опубликован» или «Шаблон опубликован ✓»),
а баннер чётко отражает режим read-only без лишней констатации статуса.

---

## Причина ошибки

**Корень проблемы:**  
Сообщения писались без единого стиля — часть описывает состояние («Шаблон опубликован»),
часть — результат действия. Ant Design `message.success` / `notification.success` и
баннер `Alert` формулируют одно и то же разными паттернами.

**Цепочка сбоя:**  
1. Пользователь публикует шаблон.
2. Появляется `message.success('Шаблон опубликован')` — неясно: это «только что опубликовали»
   или «шаблон сейчас находится в опубликованном состоянии»?
3. В TemplateDesigner тот же текст дублируется через `notification.success`.
4. Кнопка `okText="Снять"` в Popconfirm списка выглядит как «снять» без контекста.
5. Баннер `PublishedBanner` смешивает статус («опубликован») с ограничением («недоступно»).

## Поэтапное исполнение

1. **TemplateList.tsx** — заменить тексты:
   - `'Шаблон опубликован'` → `'Шаблон опубликован'` (добавить явный результат: «Шаблон успешно опубликован»)
   - `'Шаблон снят с публикации'` → `'Шаблон снят с публикации'` (норм, оставить или добавить «успешно»)
   - `okText="Снять"` → `okText="Да, снять"`
   - `message.error('Не удалось изменить статус публикации')` → раздельные сообщения для publish/unpublish
2. **TemplateDesigner.tsx** — синхронизировать `notification.success` тексты с TemplateList.
3. **PublishedBanner.tsx** — переформулировать: убрать констатацию статуса, оставить только причину read-only.

**Единый стиль (предложение):**
- Успех публикации: «Шаблон опубликован — теперь доступен для заполнения»
- Успех снятия: «Шаблон снят с публикации — закрыт для заполнения»
- Ошибка публикации: «Не удалось опубликовать шаблон»
- Ошибка снятия: «Не удалось снять шаблон с публикации»
- Баннер: «Шаблон в режиме только для чтения (опубликован)»
