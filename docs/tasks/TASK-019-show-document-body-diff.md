## Интерпретация

Пользователь хочет видеть, что именно изменилось в тексте документа между редакциями — режим «track changes» / «diff view».

Функционал: в истории редакций при выборе конкретной редакции включается режим просмотра изменений, где удалённый текст выделяется красным зачёркиванием, добавленный — зелёным подчёркиванием (стандартная визуализация diff).

Дополнительно возможна кнопка-переключатель «Показать изменения» / «Скрыть изменения» прямо в интерфейсе редактора.
