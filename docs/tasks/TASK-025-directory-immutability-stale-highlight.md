## Постановка задачи (от пользователя)

> Задача 10 из docs/backlog.md: Иммутабельность значений справочника в документах + подсветка устаревших

```
Созданный документ не должен автоматически меняться при изменении записи справочника.
Если данные источника изменились — это подсвечивается в документе.
Пользователь может применить обновлённые данные явно.
```

---

## Интерпретация

При генерации документа текущие значения полей справочника (name, bik и т.д.) замораживаются в `answers._directory_snapshots`. Дальнейшие изменения записи справочника не влияют на документ автоматически. Если запись изменилась — в редакторе документа подсвечиваются устаревшие поля с предложением применить актуальные данные явно.
