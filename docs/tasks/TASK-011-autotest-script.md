## Постановка

Нет единой точки запуска всех тестов проекта. Нужен скрипт, который одной командой запускает backend-тесты (JUnit/Testcontainers) и frontend-тесты (Vitest), собирает результаты и выводит итоговый статус.

## Интерпретация

Скрипт должен:
- Запускать backend (`./gradlew test`) и frontend (`npm test -- --run`) тесты
- Отображать результаты каждой части
- Возвращать ненулевой код завершения при любой ошибке (для использования в CI)
- Опционально: поддерживать флаги `--backend-only`, `--frontend-only`

## Файлы для изучения

- `backend/build.gradle` — задачи тестирования
- `frontend/package.json` — тестовые скрипты (vitest)
- `dev.sh` — существующий скрипт запуска (для понимания структуры)
- `backend/src/test/` — существующие тесты
- `frontend/src/` — существующие frontend-тесты (`*.test.tsx`)

## Файлы для изменения / создания

- `scripts/test.sh` — новый скрипт запуска тестов (или в корне `test.sh`)
- `README.md` или `docs/` — документация по запуску тестов

## Этапы

1. Изучить существующие тестовые скрипты backend и frontend
2. Написать `test.sh` с разделами backend / frontend
3. Добавить цветной вывод статуса (PASS/FAIL)
4. Добавить флаги `--backend-only`, `--frontend-only`
5. Проверить exit-коды при падении тестов
6. Задокументировать использование

## Тесты

- Запуск без аргументов: оба набора тестов выполняются
- Запуск `--backend-only`: только backend, frontend не запускается
- Запуск `--frontend-only`: только frontend
- При падении любого теста: скрипт возвращает exit code != 0

- [ ] Падающий тест дает ненулевой exit code
