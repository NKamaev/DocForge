## Интерпретация

Две связанных задачи:

1. **Переименование**: термин «ревизия» заменить на «редакция» — в UI-метках, TypeScript-типах, именах Java-классов и DTO. Имена таблиц/колонок в БД менять **не нужно** (это сломает Flyway-историю без очевидной пользы; достаточно переименовать Java-уровень и всё выше).

2. **Автор изменений**: сейчас `DocumentRevisionDTO` содержит только `savedBy: UUID`. Нужно добавить `authorName: String` — отображаемое имя (`displayName`) пользователя, который сохранил редакцию. Для этого в `DocumentServiceImpl` вызвать `UserService.getById(savedBy)` при маппинге в DTO.
