## Постановка задачи (от пользователя)

```
В рамках TASK-006-2 ParticipantsPanel не до конца корректно. При обновлении
второго пользователя у первого пользователя в панеле добавляется дубль второго
пользователя. Кроме того, при добавлении большого количества пользователей
панель расширяется без остановки. Нужно ограничить количество одновременно
видимых пользователей до 3. Если их больше — показывать плашку «и ещё N»,
при наведении на которую отображается список остальных пользователей,
не попавших в основные плашки.
```

---

## Причина ошибки

**Корень проблемы (дубли):**  
При обновлении awareness-состояния (например, после обновления страницы пользователем)
Yjs кратковременно оставляет в `awareness.getStates()` оба clientId — старый
(ещё не вычищенный) и новый. В итоге `updateUsers` добавляет два объекта с
разными `clientId`, но одинаковым `name`. `ParticipantsPanel` рендерит оба,
потому что ключ — `u.clientId`, а фильтрации по уникальному имени нет.

**Корень проблемы (overflow):**  
Flex-контейнер в `ParticipantsPanel` не ограничен по ширине и не имеет `maxWidth`.
При большом числе участников аватары просто раздвигают хедер.

**Цепочка сбоя:**
1. Пользователь B обновляет страницу → его awareness выходит и входит заново.
2. `awareness.change` срабатывает дважды: при disconnect (старый clientId ещё в states) и при reconnect.
3. В `users[]` оказывается два entry с разными clientId, но `name === 'B'`.
4. `ParticipantsPanel` показывает два аватара для B.
5. Аналогично: при >3 пользователях панель растёт без ограничения.

## Поэтапное исполнение

1. **Дедупликация в `useCollaboration.ts`** — в `updateUsers` после сбора массива
   `users[]` применить дедупликацию: сгруппировать по `name`, оставить entry с
   наибольшим `clientId` (последний подключившийся — самый актуальный).

2. **Ограничение видимых аватаров в `ParticipantsPanel.tsx`** — вычислить
   `visibleUsers = connectedUsers.slice(0, 3)` и
   `overflowUsers = connectedUsers.slice(3)`.

3. **Плашка «+N»** — если `overflowUsers.length > 0`, отрендерить аватар-кнопку
   с текстом `+N`. Использовать `<Tooltip title={<список имён>}>` для показа
   полного списка при наведении. Цвет плашки — нейтральный (`#8c8c8c`).

4. **Убедиться, что `currentUser` не считается в лимит** — текущий пользователь
   всегда показывается первым, лимит 3 применяется только к `connectedUsers`
   (remote).
