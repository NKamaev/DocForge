## Постановка задачи (от пользователя)

> При публикации шаблона появляется следующая надпись "Есть несохранённые изменения" хотя никаких изменений в шаблон перед публикацией не вносилось.

---

## Интерпретация

После нажатия кнопки «Опубликовать» флаг `isDirty` неожиданно становится `true`, что приводит к отображению предупреждения «Есть несохранённые изменения» в хедере TemplateDesigner, хотя пользователь не вносил никаких изменений в шаблон.

---

## Причина ошибки

**Корень проблемы:**  
TipTap's `editor.setEditable(editable)` по умолчанию вызывает `emitUpdate = true`, что триггерит событие `update` и, соответственно, `onUpdate`-коллбэк редактора → `setIsDirty(true)`.

**Цепочка сбоя:**  
1. Пользователь нажимает «Опубликовать»
2. `handlePublish` делает API-вызов, получает ответ → `setPublished(true)`
3. React re-render: `published` меняется с `false` на `true`
4. `useEffect(() => { editor.setEditable(!published) }, [editor, published])` срабатывает
5. `editor.setEditable(false)` вызывается — TipTap внутри вызывает `this.emit('update', ...)` т.к. `emitUpdate=true` по умолчанию
6. `onUpdate` коллбэк срабатывает → `setEditorJson(json)` + `setIsDirty(true)`
7. Появляется индикатор «Есть несохранённые изменения»

## Поэтапное исполнение

1. **Исправить вызов `setEditable`** — передать `false` вторым аргументом, чтобы не эмитировать `update`:
   ```typescript
   editor.setEditable(!published, false)
   ```
   Файл: `TemplateDesigner.tsx`, строка ~363.
