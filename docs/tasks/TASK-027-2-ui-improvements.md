## Конкретные задачи (по результатам TASK-027-1)

> Источник: аудит 2026-04-23. Отсортировано по приоритету.

### P0 — Исправить немедленно
- **Дублирующиеся TipTap-расширения**: убрать лишнюю регистрацию `link`/`underline` из `DocumentWorkspace.tsx`
- **Yjs-ошибки**: расследовать `Error: Unexpected end of array` — возможно несовместимость CRDT-состояния с версией y-websocket

### P1 — Навигация и структура
- **Починить схлопывание навигации**: в `AppLayout.tsx` дать Menu достаточную ширину — убрать `minWidth: 200`, поставить `flex: 1`, вынести user-блок из flex-потока Menu
- **Вкладки Designer тоже переполняются**: в `TemplateDesigner.tsx` для Tabs.items добавить `tabBarStyle` или сократить лейбл «Формулировки» → «Фразы» / дать панели больше ширины
- **Кнопка «Назад» в Designer**: добавить breadcrumb или кнопку `← Шаблоны` в шапку Template Designer
- **`destroyOnClose` → `destroyOnHidden`** в `CreateTemplateModal.tsx`

### P2 — Улучшения
- **Главная страница**: убрать «Будет доступно в следующей фазе.» из карточек, добавить реальные ссылки на `Шаблоны` и `Документы`
- **Консистентность кнопок**: `/documents` и `/directories` — добавить текстовые лейблы к иконкам (или убрать лейблы в `/templates`)
- **Цвет кнопок Справочников**: заменить фиолетовые `type="primary"` на синие (привести к стандарту antd)
- **Лейаут Справочников**: убрать ограничение ширины карточки, сделать full-width как у `/templates`
- **Empty state в read-only Designer**: убрать подсказку «Нажмите Добавить» когда шаблон опубликован
- **Скрыть пагинацию** при одной странице в `/documents`
- **React Router future flags**: в `main.tsx` добавить `future={{ v7_startTransition: true, v7_relativeSplatPath: true }}`
- **Мобильная адаптация**: для таблиц `/templates` и `/documents` добавить `scroll={{ x: 800 }}`

### P3 — Косметика
- **Font selector** в тулбаре: расширить `<Select>` до `~160px`
- **Скрыть «Системный ключ»** (`field_1`) от пользователя в `/directories/:id` или сделать только для чтения
- **Вкладка «Регистрация»**: проверить — если не реализована, убрать из `LoginPage.tsx`
