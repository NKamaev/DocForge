## Постановка задачи (от пользователя)

> Концепция изменилась: `/fill` — основное рабочее пространство. `/edit` — избыточен, пользователь туда не переходит. Нужно зафиксировать изменения и добавить на `/fill` недостающие функции.

---

## Интерпретация

Страница `/documents/:id/fill` (`QuestionnairePage`) фактически является полноценным рабочим пространством: левая панель — опросный лист, правая (`DocumentWorkspace`) — полноценный TipTap-редактор с тулбаром, не уступающий `/edit`.

Однако есть три критических gap-а, которые делают `/fill` функционально неполным:

1. **Правки текста не сохраняются** — `DocumentWorkspace` рендерит шаблон при каждой загрузке; `current_body` не читается и не пишется. Свободные правки текста теряются при перезагрузке.
2. **Нет Yjs-коллаборации** — несколько пользователей не могут одновременно редактировать документ на `/fill`.
3. **Нет ревизий** — отслеживается в BUG-005.

`/edit` (`DocumentEditor`) не доступен из навигации — на него нет ни одной ссылки в компонентах. После достижения паритета маршрут удаляется.
