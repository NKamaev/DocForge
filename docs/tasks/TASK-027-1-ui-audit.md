## Постановка задачи

Провести полный аудит UI/UX приложения DocForge: пройти все сценарии от лица пользователя, зафиксировать проблемы. Результат — структурированный список с категориями и приоритетами, который станет входом для TASK-027-2.

---

## Вопросы для исследования

1. **Навигация и ориентация** — легко ли пользователь понимает где он находится и что делать дальше?
2. **Состояния и обратная связь** — есть ли индикаторы загрузки, ошибок, успеха? Понятны ли они?
3. **Визуальная иерархия** — выделены ли главные действия? Нет ли визуального шума?
4. **Консистентность** — одинаково ли оформлены кнопки, иконки, отступы, типографика по всему приложению?
5. **Пустые состояния** — есть ли понятные empty state для списков, страниц?
6. **Мобильная адаптация** — корректно ли выглядит на разных разрешениях?
7. **Редактор шаблонов** — удобен ли тулбар, вставка блоков, настройка условий?
8. **Страница заполнения (/fill)** — понятен ли опросник, видны ли все вопросы?
9. **Страница документов** — понятна ли таблица, экспорт, история редакций?
10. **Публикация шаблонов** — чёткий ли флоу публикации/снятия?

---

## Сценарии для прохода

### Сценарий A: Создание и публикация шаблона
1. Войти → список шаблонов
2. Создать новый шаблон
3. Добавить текст, условный блок, таблицу
4. Настроить условие
5. Опубликовать шаблон

### Сценарий B: Работа с документом
1. Создать документ на основе шаблона
2. Заполнить опросник
3. Редактировать тело документа
4. Посмотреть историю редакций
5. Экспортировать в DOCX/PDF

### Сценарий C: Коллаборация
1. Открыть документ в двух вкладках
2. Проверить индикатор участников
3. Убедиться в синхронизации правок

### Критические проблемы (P0)

- [x] **Дублирующиеся TipTap-расширения** — `link` и `underline` зарегистрированы дважды в `DocumentWorkspace`. Консоль: `[tiptap warn]: Duplicate extension names found: ['link', 'underline']`. Может приводить к непредсказуемому поведению редактора. Файл: `components/questionnaire/DocumentWorkspace.tsx`.
- [x] **Yjs-ошибки при загрузке документа** — два раза `Error: Unexpected end of array` при обработке Yjs-обновлений. Возможна повреждённая/несовместимая CRDT-структура для существующего документа. Файл: `hooks/useCollaboration.ts` (y-websocket).

---

### Важные проблемы (P1)

- [x] **Навигация всегда схлопывается в "..."** — пункты «Мои документы», «Шаблоны», «Справочники» скрыты за overflow-меню даже при ширине 1440px. Причина: `<Menu style={{ flex: 1, minWidth: 200 }} />` в контейнере `flex` без явного расширения. Файл: `components/AppLayout.tsx:30–37`.
- [x] **Вкладки правой панели Designer переполняются** — «Формулировки» обрезается, «Скрипты» скрыты за "…" (тот же паттерн). Файл: `components/template-designer/TemplateDesigner.tsx:390–436`.
- [x] **`destroyOnClose` устарел** — консольная ошибка `[antd: Modal] destroyOnClose is deprecated. Please use destroyOnHidden instead.` на странице шаблонов. Нужно заменить в `CreateTemplateModal`.
- [x] **Нет кнопки «Назад» в Template Designer** — единственный способ вернуться к списку — нажать «Главная» и снова перейти в «Шаблоны» через скрытое меню. Файл: `components/template-designer/TemplateDesigner.tsx`.

---

### Улучшения (P2)

- [x] **Главная страница: устаревший placeholder** — обе карточки содержат «Будет доступно в следующей фазе.» несмотря на то что Шаблоны и Документы полностью реализованы. Файл: `pages/HomePage.tsx`.
- [x] **Главная страница пустая** — нет статистики, последних документов, быстрых действий. После логина непонятно, что делать дальше.
- [x] **Мобильная адаптация таблиц отсутствует** — на 375px колонки «Дата создания» и «Действия» в `/templates` и `/documents` выходят за экран, таблица горизонтально скроллируется но не адаптируется.
- [x] **Неконсистентные кнопки действий** — в `/templates` кнопки с иконкой + текстом («Открыть», «Снять»), в `/documents` и `/directories` — только иконки без подписей.
- [x] **Несоответствие цвета кнопок в Справочниках** — «Новый справочник», «Добавить поле», «Добавить запись» — фиолетовые, тогда как везде используется синий `type="primary"`. Файл: `pages/DirectoriesPage.tsx`, `pages/DirectoryDetailPage.tsx`.
- [x] **Несоответствие ширины лейаута** — `/templates` и `/documents` занимают всю ширину, `/directories` и `/directories/:id` — центрированная карточка ~870px. Нет консистентности.
- [x] **Empty state в read-only режиме** — на опубликованном шаблоне панель «Параметры (0)» отображает «Нажмите «Добавить» чтобы создать первый.» хотя кнопки «Добавить» нет. Файл: `components/template-designer/ParameterPanel.tsx`.
- [x] **Пагинация при 1 странице** — `/documents` показывает пагинатор даже если документ один. Нужно скрывать при `totalElements <= pageSize`. Файл: `components/document-list/MyDocuments.tsx`.
- [x] **React Router future-flag warnings** — два предупреждения `v7_startTransition` и `v7_relativeSplatPath` в консоли. Решается добавлением `future` флагов в `BrowserRouter`. Файл: `main.tsx`.

### Косметика (P3)

- [x] **Шрифт в тулбаре обрезается** — `<Select>` для шрифта показывает «Times New R…» — слишком узкий. Файл: `components/template-designer/EditorToolbar.tsx`.
- [x] **«Системный ключ» виден пользователю** — в `/directories/:id` показывается техническое поле `field_1`. Если это не нужно пользователю — скрыть или сделать нередактируемым. Файл: `pages/DirectoryDetailPage.tsx`.
- [x] **Вкладка «Регистрация» на логине** — неясно реализована ли регистрация. Если нет — убрать вкладку. Файл: `pages/LoginPage.tsx`.
- [x] **`findDOMNode` deprecation-warnings** от Ant Design ColorPicker в консоли (библиотечная проблема, требует обновления antd до версии с фиксом).
