## Постановка задачи (от пользователя)

```
в документе http://localhost:5173/documents/c5e5e602-8e06-48fa-86b7-2fa1dbe79eb7/fill
одновременно отображаются три абзаца:
- Наша организация, покупатель ЮЛ
- Наша организация, покупатель ИП
- Наша организация, покупатель ФЛ

хотя по настройкам шаблона их отображение зависит от ответа на вопрос "Тип клиента"
```

---

## Интерпретация

На странице `/fill` условные блоки (ConditionalBlock) отображаются все сразу, независимо от текущего ответа на связанный вопрос. Ожидаемое поведение: виден только тот блок, условие которого выполняется согласно ответам опросного листа.

---

## Причина ошибки

**Корень проблемы:**  
Компонент, отвечающий за рендеринг условных блоков на `/fill`, либо не получает актуальные ответы из опросника, либо логика видимости не применяется при начальной загрузке и при изменении ответов.

**Цепочка сбоя:**  
1. Пользователь открывает `/fill` — ответы ещё не выбраны или загружаются асинхронно.
2. ConditionalBlock получает пустой/неинициализированный контекст ответов.
3. Условие видимости вычисляется как `true` для всех блоков (fallback или отсутствие проверки).
4. Все три блока «Наша организация, покупатель X» отображаются одновременно.

## Поэтапное исполнение

1. **Изучить** как ConditionalBlock получает контекст ответов — через props, context API или store.
2. **Найти** место, где вычисляется видимость блока (условие `if answer === value`).
3. **Выявить** когда answers пустые/undefined — возвращает ли компонент `true` вместо `false`.
4. **Исправить** логику: если ответ отсутствует → блок скрыт (или показан дефолтный).
5. **Проверить** реактивность: изменение ответа → немедленное обновление видимости блоков.
