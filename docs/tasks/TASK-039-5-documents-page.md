## API

Для папок и документов нужны эндпоинты:
- `GET /api/folders` — дерево папок
- `GET /api/documents?folderId=` — документы в папке

## Поэтапное исполнение

### 1. Layout (`.docs-page`)
```css
.docs-page { display: grid; grid-template-columns: 240px 1fr; height: calc(100vh - var(--topbar-h)); }
```

### 2. Дерево папок (`.docs-tree`)
- Фиксированный заголовок + кнопка «Создать папку»
- Корень «Все документы» (иконка home) с общим счётчиком
- Разделитель `.tree-divider`
- Рекурсивный `TreeNode`:
  - Отступ `paddingLeft = 8 + depth * 14`
  - Кнопка-треугольник expand/collapse (`.tree-tri`) — скрыта если нет детей
  - Цветная иконка folder (`.tree-folder-icon`, цвет из `oklch(0.55 0.13 {hue})`)
  - Название (`.tree-label`) + счётчик (`.tree-count`)
  - Активная строка: `.tree-row.current`

### 3. Переключатель вида + Заголовок
- `.page-head` с breadcrumb, h1, подзаголовком
- `.seg` — сегмент-контрол: кнопки список/плитка

### 4. Bulk-actions bar (`.bulk-bar`)
- Появляется при `selected.size > 0`
- «Выбрано: N» + Переместить / Скачать / Удалить (danger) / Снять выбор

### 5. Список (`.tbl`)
- Чекбокс select-all в `<thead>`
- Строка «← на уровень выше» (`.row-up`) для вложенных папок
- Строки папок (`.row-folder`): цветная иконка + название + «Папка · N вложенных»
- Строки документов: иконка (check/doc) + название (clickable) + шаблон + прогресс + автор + дата + row-actions
- Прогресс-бар зелёный для `complete`

### 6. Плитка (`.docs-grid`)
- `FolderCard`: цветная иконка + название + «N dok. · M папок»
- `DocCard`: иконка + название + шаблон + footer (дата + прогресс%)
- Кнопка «← на уровень выше» если есть родительская папка
