# Лучшие практики DocForge

> Тег: `practices:best-practices` · Обновлено: `2026-10-10`

## Источник истины

- **Код и данные приложения — источник истины.** Если тег памяти/документация противоречит коду — верь коду, тег пометь устаревшим и обнови. Никогда не следуй устаревшей справке вопреки наблюдаемому поведению.

## Процесс и делегирование

- Главный агент — координатор: разбирает эпик, делегирует по однодоменным задачам спецагентам (`@backend`, `@frontend`, `@test`, `@review` и т.д.), проверяет результат.
- Мелкие задачи (1–5 файлов, явный паттерн, контекст уже загружен) можно делать напрямую. При неуверенности — делегируй.
- Правила: тесты пишет только `@test`, TipTap-расширения — только `@tiptap-specialist`, Docker/CI — только `@devops`, Flyway — `@migrate`/`@backend`, ревью — только `@review`.
- Эйпичный процесс фичи: PRD → `@architect` → `@backend`/`@frontend` → `@test` → `@review` → commit.

## Слои и модули

- Модули общаются только через `*Service` интерфейсы; никогда — через чужие Repository.
- Controller тонкий; сервис — вся логика; DTO — Java records.
- Flyway — единственный источник схемы (JPA `ddl-auto: validate`).

## Качество/работа с редактором

- У TipTap NodeView — один стабильный render; скрытие через style (см. pitfalls).
- `setContent` при инициализации — `{ emitUpdate: false }` (TASK-009).
- Seeding на /fill: ждать WS-sync, Yjs-контент побеждает REST (BUG-020 паттерн).
- Экспорт применяет ту же фильтрацию условий, что и генерация (BUG-019 урок).

## Память

- В начале сессии: tag-index → всегда `best-practices` + `pitfalls-*` → тематические теги.
- В конце сессии: тег/тикет → daily → `memory-lint.sh` → commit `.memory/`.
- Категории тегов: `architecture`, `frontend`, `conventions`, `pitfalls`, `practices`, `tickets`.
