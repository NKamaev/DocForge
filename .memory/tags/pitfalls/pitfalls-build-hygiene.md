# Pitfalls — гигиена сборки и артефактов

> Тег: `pitfalls:build-hygiene` · Обновлено: `2026-10-12`

## Класс проблем: stray-артефакты и затенение исходников

### Stray `.js` рядом с `.ts`/`.tsx` (TASK-064)
- **Симптом:** поведение фронтенда не соответствует правкам в `.ts`/`.tsx`; тесты/сборка используют «старый» код.
- **Корень:** отменённый агент разом эмитнул 148 (+2) `.js` в `frontend/src`. Vite/esbuild резолвит `./module` → **`.js` раньше `.tsx`** → компилируемый `.js` затеняет исходник. Проявлялось как «фиксы не применяются».
- **Почему не видно:** при untracked-каталоге `git status --short` показывает строку каталога, а не отдельные `.js`-файлы.
- **Детект:** `find frontend/src -name '*.js'` (должно быть пусто) — включать в верификацию.
- **Профилактика:** в промптах агентам запрещать эмит `.js`; транспайл без записи (`tsc -b`, `npm run build` в свой `outDir`).

### Мёртвые артефакты после смены подхода
- При отказе от старого решения (напр. plain-text diff → structural) удалять и код, и зависимости (`java-diff-utils` в `build.gradle.kts`), и DTO (`DiffChunk`) в том же изменении.
