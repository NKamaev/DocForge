# BUG-012 — Все условные блоки видны одновременно на /fill

- **Статус:** закрыт (DONE, commit `303a535`)
- **Дата:** 2026-04-18
- **Агенты:** `/frontend`
- **GitHub Issue:** [#30](https://github.com/NKamaev/DocForge/issues/30)

## Суть

На /fill одновременно отображаются блоки для «ЮЛ/ИП/ФЛ», хотя их видимость зависит от ответа.

## Причина

Рендер условных блоков не применял условия при инициализации/изменении ответов.

## Решение

Применять `evaluateSimple`/проверку условий на старте и по изменению ответов (паттерн `updateHiddenPositions`, storage-канал в workspace). См. тег `pitfalls:conditional-rendering`.
