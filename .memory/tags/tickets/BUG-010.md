# BUG-010 — Ответы и опросный лист не синхронизируются в реальном времени

- **Статус:** закрыт (DONE, commit `d251868`)
- **Дата:** 2026-04-18
- **Агенты:** `/frontend`
- **GitHub Issue:** [#21](https://github.com/NKamaev/DocForge/issues/21)

## Суть

При совместной работе текст синхронизируется сразу, но опросный лист и чипы параметров — только после reload.

## Причина

Ответы хранились в локальном React-state, а не в Yjs. Чипы берут значения из `storage.answers` → props → локальный state.

## Решение (паттерн)

Единый канал `yAnswers = ydoc.getMap('answers')`; observer в обе стороны: локальный → `yAnswers.set()`, удалённый → мерж в state + пере-фетч ОЛ (`QuestionnairePage.tsx:214-248`). Подробности: тег `pitfalls:yjs-sync`.
