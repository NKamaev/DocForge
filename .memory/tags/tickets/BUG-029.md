# BUG-029 — Toast не показывался программно (module-level listeners)

- **Статус:** закрыт (commit `3c6ea0b`)
- **Дата:** 2026-04 (реконструкция 2026-10-10)
- **Агенты:** `/frontend`

## Суть

Программные уведомления не отображались: модульные/глобальные слушатели событий были хрупкими (стреляли мимо, дублировались в StrictMode-монтировании).

## Решение

Toast реализован через CustomEvent `app-toast`: `showToast(msg, 'success'|'error')` из `ui/toast` диспатчит событие, `ToastContainer` слушает. Программный путь покрыт e2e `toast-debug.spec.ts` (`CustomEvent('app-toast')` + `data-testid="toast-container"`).

## Источники

- git `3c6ea0b`, тег `frontend:api-layer` (раздел уведомлений).
