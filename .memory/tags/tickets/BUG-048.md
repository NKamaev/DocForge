# BUG-048 — Несогласованный permission-check на revision/document эндпоинтах

- **Статус:** открыт
- **Создан:** 2026-10-10
- **Источник:** ревью TASK-019-1 / отчёт @test

## Суть

Новый diff-эндпоинт `GET /api/documents/{id}/revisions/{revNum}/diff` проверяет
`DocumentPermission.READ`, но соседние эндпоинты — нет:

- `GET /api/documents/{id}/revisions`
- `GET /api/documents/{id}/revisions/{revNum}`
- `POST /api/documents/{id}/revisions/{revNum}/restore`
- `PUT /api/documents/{id}/questionnaire/answers`
- `POST /api/documents/{id}/generate`

Пользователь без доступа к документу потенциально может читать/восстанавливать
его редакции или менять ответы. Несогласованность enforcement.

## Что сделать

Добавить `DocumentPermission.READ` (для restore/write — соответствующий грейд)
на все перечисленные эндпоинты по образцу `getById`/`getRevisionDiff` в
`backend/src/main/java/com/docforge/document/DocumentController.java`.
