# BUG-054 — Конфликт нумерации версий publish() и saveVersion()

- **Статус:** закрыт (2026-10-22)
- **Источник:** ревью BUG-053 (BLOCKER B1)

## Суть

Два разных аллокатора писали в одну колонку
`template_version.version_number` (UNIQUE `(template_id, version_number)`):

- `saveVersion()`/`rollback()` — семантически: `major * 10000 + minor`;
- `publish()` — `max(pgMax, mongoMax) + 1`.

Воспроизведение на dev:

```
saveVersion(MINOR) -> 10001 (1.1)
publish()          -> 10002, registry.version=10002, но major/minor остались 1/1
saveVersion(MINOR) -> 10002 -> DataIntegrityViolationException -> 500
```

## Решение (коммит `c0f4730`)

- Единый приватный аллокатор `allocateVersion(registry, templateId, bumpType)`
  (record `NextVersion`) для **всех трёх** писателей:
  - `MAJOR` → `major+1, minor=0`;
  - `MINOR` / `PUBLISH` / `ROLLBACK` → `minor+1`;
  - overflow `minor > 9999` → `major+1, minor=0`;
  - `max(pgMax, mongoMax)` — **только floor монотонности** для «осиротевших»
    снимков (Mongo пишется вне JPA-транзакции), не источник нумерации.
- `registry`, `TemplateVersion` и `TemplateSnapshot` всегда получают один и
  тот же тройной номер — рассинхрон `version=10002 / 1.1` устранён.
- `toVersionDTO`: легаси-счётчики (`< 10000`) с null-компонентами рендерятся
  как `vN.0`, а не `vN.N` (было `3` → «v3.3»).
- **Миграция `V017__repair_template_version_components.sql`** — выравнивает
  компоненты существующих строк. Только labels: `version_number` не меняется,
  поэтому пины `document_registry.template_version_number` продолжают
  резолвиться.
- **Тесты:** `TemplateVersionNumberingIT` — 8 кейсов (регрессия
  save→publish→save, консистентность registry, 3× unpublish/publish, rollback,
  MAJOR, overflow, легаси-labeling, старые «сломанные» компоненты);
  `TemplateServiceImplTest` — unit на overflow.

## Проверка на dev

- `1.0 → publish 1.1 → publish 1.2`; `save 1.1 → publish 1.2 → save 1.3` (было 500);
- `rollback → 1.3`, `save MINOR → 1.4`, `MAJOR → 2.0`, `publish → 2.1`;
- ранее сломанная строка (`10002 / 1.1`) после V017 → `saveVersion(MINOR)` = 1.3;
- документ с явным опубликованным `templateVersionNumber` создаётся (201).

## Ревью

REQUEST CHANGES → исправлено:

- **W1** — аллокатор был только для `publish`; `saveVersion`/`rollback` всё ещё
  могли упасть на существующих «сломанных» данных. Теперь все три вызывают
  `allocateVersion`.
- **W2** — добавлена миграция `V017` для существующих несогласованных строк.
- **W3** — fallback `toVersionDTO` для легаси (`vN.0`).
- **W4** (draft `version=1` vs semver-шкала) и NIT'ы — вынесены/учтены;
  **BUG-062** — черновик `version=1` при `major/minor=1.0`.
