# BUG-046 — Откат к редакции: Yjs-reset вместо reload страницы

- **Статус:** закрыт (commits `a89a7df`, `6e17e84`, `a2e031e`)
- **Дата:** 2026-10 (реконструкция из git)
- **Агенты:** `/frontend`

## Суть

Restore-редакции на /fill приводил к `window.location.reload()` — грузное и ломавшее коллаборацию решение.

## Решение

Программный reset: очистить Yjs fragment + `yAnswers.clear()`, пере-загрузить REST-состояние, реюз канвы через `restoreSeedKey` (детали: `QuestionnairePage.tsx:264-309`). Также зафиссены null-типы для `RevisionMeta` (`a89a7df`).
