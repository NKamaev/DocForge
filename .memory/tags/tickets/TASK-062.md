# TASK-062 — Diff не учитывает изменения значений параметров

- **Статус:** открыт
- **Создан:** 2026-10-10
- **Источник:** ревью TASK-019-2

## Суть

`computeRevisionDiff` диффит текст тела документа (`current_body`/`generated_body`).
Значения параметров хранятся в `answers` документа, а не в теле, поэтому diff
не покажет изменение значения, если пользователь поменял только ответ в ОЛ.

## Что сделать

Рассмотреть включение значений параметров (или их снапшота) в источник diff —
либо явно задокументировать ограничение. Связано с `frontend:workspace` /
`architecture:generation-pipeline`.
