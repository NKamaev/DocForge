# BUG-057 — Кнопка «Импорт DOCX» на главной не имеет обработчика

- **Статус:** закрыт (2026-10-22)
- **Создан:** 2026-10-22
- **Источник:** разбор BUG-045 (тестовые дубликаты «кнопка не работает»)

## Суть

На `/` в `page-head-actions` рендерилась активная кнопка «Импорт DOCX» без
`onClick` — клик не давал никакого фидбэка. Импорт из DOCX явно вне MVP
(`docs/architecture.md` §1.3), но UI обещал фичу.

## Решение (коммит `25b830a`)

- Кнопка **удалена** (а не disabled): title/tooltip на `disabled`-кнопке
  недоступен пользователю (нет pointer events, нет tab-фокуса), AT остаётся
  без пояснения.
- Copy «Быстрые действия → Создать шаблон» заменён с
  «Начните с пустой страницы или импортируйте DOCX.» на
  «Начните с пустой страницы или выберите готовый шаблон.»
- **Тесты:** `HomePage.test.tsx` — нет кнопки /Импорт DOCX/i; нет текста
  «импортируйте DOCX»; есть новый copy; «Новый шаблон» ведёт на `/templates`.
  Frontend suite **130/130**, `tsc -b` OK.

## Ревью

REQUEST CHANGES на первом варианте (disabled + `title`). Warning'и:
- `title` на disabled не показывается, клавиатура/AT не получают объяснения;
- copy в «Быстрых действиях» продолжал рекламировать импорт DOCX.
Исправлено удалением кнопки + заменой copy.

## Связанные

- BUG-045 — тестовые дубликаты «кнопка не работает», закрыты как мусор
  со ссылкой на этот тикет.
