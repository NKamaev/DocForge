# BUG-049 — DocumentsPage: bulk-кнопки «Скачать»/«Удалить» не работают

- **Статус:** закрыт (2026-10-22)
- **Создан:** 2026-10-13
- **Источник:** ревизия REVIEW-колонки / аудит легаси-эпика TASK-039

## Суть

В `frontend/src/pages/DocumentsPage.tsx` (bulk-bar, ~строки 760-761) кнопки
массовых действий «Скачать» и «Удалить» отрисованы, но без обработчика `onClick`
— UI-only, действия не выполняются.

## Что сделать

Реализовать массовое скачивание и массовое удаление выбранных документов
(подтверждение, обработка ошибок), либо, если фича не планируется, убрать или
задизейблить кнопки.

- **Файлы:** `frontend/src/pages/DocumentsPage.tsx`, `frontend/src/api/documentsApi.ts`.
- **Приёмка:** Playwright-тест bulk-выбор → скачивание/удаление; осмысленное
  состояние кнопок (disabled при пустом выборе).
- **Агент:** `/frontend`.

## Решение (коммит `7736bf1`)

- **Bulk download:** per-item `exportDocx`; прогресс «Скачивание N/M»;
  частичный сбой не прерывает остальные; итог «Скачано X из Y»; имена файлов
  sanitize + дедуп; anchor добавляется в DOM, `revokeObjectURL` — отложенно.
- **Bulk delete:** диалог подтверждения, остаётся открытым в busy-состоянии
  (`preventDefault` на `AlertDialogAction`), закрывается в `finally`;
  per-item `delete`, succeeded-ids вычищаются из выбора, список перезагружается
  всегда; count-aware итог.
- Выбор сбрасывается при смене папки (включая back/forward); счётчик показывает
  документы + «(папок: N)».
- Ре-энтранси guard + `useCallback`; `aria-label` на select-all; плюрализация;
  `allChecked` не считается по папкам.
- Уведомления через `showToast`; `ToastType` расширен `warning` (amber).
- **Тесты:** `DocumentsPage.test.tsx` 5/5 (partial failure, confirm gate,
  folder-only disabled); `frontend/e2e/documents-bulk.spec.ts` 3/3 (bulk bar,
  cancel — no-op, реальное скачивание `.docx`). `tsc -b` OK.
- **Ревью:** REQUEST-CHANGES → исправления → **APPROVE**.
