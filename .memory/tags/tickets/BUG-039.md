# BUG-039 — Белый экран при создании документа (/documents)

- **Статус:** закрыт как невоспроизводимый/устаревший (2026-10-22)
- **Создан:** 2026-05-12
- **Источник:** audit_log 148, `/documents`

## Суть

При нажатии «Создать документ» на `/documents` появлялся белый экран,
блокирующий приложение. Отчёт датирован **2026-05-12** — до миграции
Ant Design → shadcn/ui.

## Проверка (2026-10-22, Playwright, текущая shadcn-UI)

| Пункт | Результат |
|---|---|
| Модалка открывается, содержимое видно | ✅ |
| Белый экран / блокировка | ❌ не воспроизводится |
| Список шаблонов загружается | ✅ |
| Выбор версии шаблона | ✅ «v1.0 (опубликована)» |
| Создание документа | ✅ 201 → `/documents/{id}/fill` |
| `body.pointerEvents` после Отмена/Escape/ошибки | ✅ восстанавливается |
| Ошибки модалки в консоли | ✅ нет |

Вывод: дефект относится к Ant Design-эпохе и устранён миграцией UI.

## Побочные находки

- **BUG-053** (исправлен, `d80c55a`): создание документа падало с 500 из-за
  дублей снимков шаблона. Обнаружено именно при воспроизведении BUG-039.
- **BUG-056** (TODO): Yjs `Unexpected end of array` в консоли на `/fill`
  (к модалке создания не относится).
