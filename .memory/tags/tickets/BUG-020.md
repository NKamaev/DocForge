# BUG-020 — yAnswers инициализируется из REST до завершения WS-синхронизации

- **Статус:** закрыт
- **Дата:** 2026-04-20
- **Агенты:** `/frontend`
- **GitHub Issue:** [#67](https://github.com/NKamaev/DocForge/issues/67)
- **Связано:** BUG-010 (WARNING #1)

## Суть

Гонка: `yAnswers.size === 0` проверяется до завершения initial WS-sync. Пользователь B перезаписывает актуальное Yjs-состояние устаревшими REST-данными.

## Решение (паттерн)

Seeding guard: дожидаться WS-sync перед записью REST-ответов в Yjs; Yjs-контент побеждает (`DocumentWorkspace.tsx:163-190`, `seededRef`). См. `pitfalls:yjs-sync`.
