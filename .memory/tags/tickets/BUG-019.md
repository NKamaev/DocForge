# BUG-019 — Скрытые по условию блоки попадают в DOCX и PDF

- **Статус:** закрыт (2026-10-23)
- **Коммит:** `9d972fe`
- **Агенты:** `/backend`, `/test`, `/review`

## Суть

`DocumentController.applyAnswers()` подставлял значения параметров, но не
вычислял условия вариативности. `current_body` документа (редактор на `/fill`
держит условные узлы как узлы) попадал в экспортёры как есть, и
`DocxExportServiceImpl` / `PdfExportServiceImpl` рендерили `conditionalBlock`
и `conditionalInline` **безусловно**.

## Воспроизведение (API)

1. Шаблон с `has_penalty == true` вокруг `HIDDEN_BLOCK_TEXT` и
   `HIDDEN_INLINE_TEXT`.
2. `POST /api/documents` → `PUT .../questionnaire/answers` с
   `has_penalty=false` → `PUT .../body` с исходным деревом.
3. `GET .../export/docx|pdf` → **200**, но в тексте присутствуют оба скрытых
   маркера (`HIDDEN_BLOCK_TEXT`, `HIDDEN_INLINE_TEXT`).
4. После фикса — маркеров нет; при `has_penalty=true` — присутствуют.

## Решение

Новый `document/generator/ConditionalNodeFilter`:

- собственный рекурсивный обход (**не** `TipTapTreeWalker` — тот не
  переприменяет трансформер к развёрнутому узлу, из-за чего вложенный
  `conditionalBlock` протекал наружу невычисленным);
- `conditionalBlock` / `conditionalInline`: `false` → узел удаляется,
  `true`/пустое условие → разворачивается в детей;
- `numberedClause` с ложным `attrs.condition` → удаляется целиком;
- `type: "python"` → `PythonConditionEvaluator`; `ScriptExecutionException` и
  `IllegalArgumentException` → **fail-closed** (как в `DocumentGenerator`);
- входное дерево не мутируется (structural sharing).

`applyAnswers()` теперь: **фильтрация условий → нумерация пунктов →
подстановка параметров/clauseRef → экспорт**. Нумерация после фильтра важна:
скрытые пункты не должны занимать номера.

## Тесты

- `backend/src/test/java/com/docforge/document/generator/ConditionalNodeFilterTest.java`
  — 24 теста: block/inline true/false, `numberedClause`, пустое/отсутствующее
  условие, python (mock) + fail-closed, вложенность 2 и 3 уровня (block и
  inline), обработка корневого узла, отсутствие мутации.
- `DocumentControllerApplyAnswersTest` — 19 тестов, включая проверку реальных
  байтов DOCX (`word/document.xml`) и PDF (`%PDF` + текст): скрытое не
  экспортируется, видимое — экспортируется, вложенное скрытое не протекает.
- `document.* + export.*` — 251 тест, 2 известных пре-существующих падения
  (stale MANAGER/SHARE assert; `UnexpectedRollbackException` → BUG-061).

## Ревью

**APPROVE** (без блокеров). Замечания вынесены:

- **TASK-066** — пайплайн экспорта живёт в контроллере (480 строк, 11
  зависимостей), вынести в сервис.
- **BUG-064** — `DocumentGenerator` не обрабатывает `conditionalInline` и
  иначе трактует отсутствующее условие; нужен единый фильтр.
- **BUG-065** — `NodeResolver` читает `attrs.clauseId`, а схема пишет
  `attrs.id`/`attrs.refId` → `clauseRef` всегда «п. ?».
- **BUG-066** — экспорт теряет текст видимого `numberedClause` (block-контент
  рендерится как inline).
- **BUG-067** — `HttpMessageNotReadableException` → 500 вместо 400.
