# BUG-019 — Скрытые по условию блоки попадают в DOCX и PDF

- **Статус:** закрыт
- **Дата:** 2026-04-19
- **Агенты:** `/backend`
- **GitHub Issue:** [#65](https://github.com/NKamaev/DocForge/issues/65)

## Суть

После BUG-018 экспорт стал подставлять параметры, но conditionalBlock/conditionalInline в DOCX/PDF рендерятся всегда, без проверки условий.

## Причина

`renderNode` в `DocxExportServiceImpl`/`PdfExportServiceImpl` для `conditionalBlock` безусловно рендерил детей.

## Решение

В экспортных рендерах применять ту же фильтрацию условий (`ConditionEvaluator`), что `DocumentController.applyAnswers`. Урок зафиксирован в `architecture:export` и `pitfalls:conditional-rendering`.
