# BUG-043 — Пустой опросный лист: «Страница 1 из 0» и активная «Далее»

- **Статус:** закрыт (2026-10-22)
- **Создан:** 2026-10-13
- **Источник:** audit_log 326, `/documents/{id}/fill`

## Суть

При `questionnaire.pages = []`:
- счётчик показывал «Страница 1 из 0»;
- `isLast = currentPage === pages.length - 1` → `0 === -1` → false, поэтому
  рендерилась активная «Далее», бесконечно увеличивавшая `currentPage`;
- заголовок страницы говорил «Страница 1 · 0 вопр.».

## Решение (коммит `5060e27`)

- `hasPages` / `pageLabel`: счётчик «Страница 0 из 0» при пустом ОЛ.
- `isLast = hasPages && currentPage === pages.length - 1`; «Далее» получает
  `disabled={!hasPages}`, клик клампится в валидный диапазон
  (`Math.min(p+1, Math.max(pages.length-1, 0))`) — защита даже при обходе
  disabled.
- Пустое состояние: заголовок «Опросный лист пуст», тело «В опросном листе
  нет вопросов» (раньше — «Нет вопросов на этой странице»).
- `useEffect` клампит `currentPage`, если число страниц уменьшилось после
  перезагрузки/удалённого обновления.
- **Тесты:** 4 новых кейса (пустой счётчик + disabled, клик — no-op, одна
  страница, две страницы sanity). Файл 15/15, полный suite 120/120, `tsc -b` OK.
- **Ревью: APPROVE** (warning про уменьшение страниц и suggestion про текст
  пустого состояния исправлены; dead-clamp оставлен как defensive).
