# 2026-10-23

## [00:05] BUG-021 закрыт — NPE на узле без `type` при экспорте

- **Причина:** `applyAnswers()` использовал `switch ((String) node.get("type"))`;
  Java switch на null → NPE. Узел без `type` возможен в `current_body` после
  TipTap/Yjs-правок.
- **Воспроизведено:** `PUT /documents/{id}/body` с узлом без `type` → экспорт
  DOCX и PDF = **500**.
- **Фикс (`9619f81`):** `switch (String.valueOf(node.get("type")))` — typeless
  уходит в `default` и пробрасывается verbatim (контракт экспортёров:
  `default -> children`). Побочно убран и CCE на не-строковом `type`.
- **Тесты:** новый `DocumentControllerApplyAnswersTest` — 9 кейсов, реальный
  `TipTapTreeWalker` + реальные экспортёры; RED на HEAD 7/9. Регрессия
  `parameterField`/DATE. `document.* + export.*` 217/2 (оба — BUG-061).
- **Ревью APPROVE.** W1 (небезопасные касты `attrs`/`bodyMap` → 500) вынесен в
  **BUG-063** вместе с мёртвым `DocxConverter`.
- **Урок:** `switch` на `String` требует `String.valueOf`, иначе null-узлы
  роняют весь экспорт; тот же паттерн уже был в экспортёрах — новые ветки кода
  должны следовать ему.
