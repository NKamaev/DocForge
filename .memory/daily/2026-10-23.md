## [00:05] BUG-021 закрыт — NPE на узле без `type` при экспорте

- **Причина:** `applyAnswers()` использовал `switch ((String) node.get("type"))`;
  Java switch на null → NPE. Узел без `type` возможен в `current_body` после
  TipTap/Yjs-правок.
- **Воспроизведено:** `PUT /documents/{id}/body` с узлом без `type` → экспорт
  DOCX и PDF = **500**.
- **Фикс (`9619f81`):** `switch (String.valueOf(node.get("type")))` — typeless
  уходит в `default` и пробрасывается verbatim (контракт экспортёров:
  `default -> children`). Побочно убран и CCE на не-строковом `type`.
- **Тесты:** новый `DocumentControllerApplyAnswersTest` — 9 кейсов, реальный
  `TipTapTreeWalker` + реальные экспортёры; RED на HEAD 7/9. Регрессия
  `parameterField`/DATE. `document.* + export.*` 217/2 (оба — BUG-061).
- **Ревью APPROVE.** W1 (небезопасные касты `attrs`/`bodyMap` → 500) вынесен в
  **BUG-063** вместе с мёртвым `DocxConverter`.
- **Урок:** `switch` на `String` требует `String.valueOf`, иначе null-узлы
  роняют весь экспорт; тот же паттерн уже был в экспортёрах — новые ветки кода
  должны следовать ему.

## [23:40] BUG-019 закрыт — скрытые условия протекали в DOCX/PDF

- **Причина:** `applyAnswers` подставлял параметры, но не вычислял условия;
  экспортёры рендерили `conditionalBlock`/`conditionalInline` безусловно.
- **Воспроизведено:** шаблон `has_penalty == true`, ответ `false`,
  `PUT /documents/{id}/body` с условным деревом → в DOCX и PDF присутствуют
  `HIDDEN_BLOCK_TEXT` и `HIDDEN_INLINE_TEXT` (оба 200).
- **Фикс (`9d972fe`):** `ConditionalNodeFilter` — собственный рекурсивный
  обход (не `TipTapTreeWalker`: тот не перепроверяет развёрнутые узлы, из-за
  чего вложенный блок протекал). Скрытые block/inline/пункты удаляются,
  видимые разворачиваются, пустое условие = видимо, python fail-closed.
  `applyAnswers`: фильтр → нумерация пунктов → подстановка.
- **Проверка:** после фикса скрытое отсутствует в обоих форматах; при `true` —
  присутствует; вложенный `false` внутри `true` не протекает (block и inline,
  3 уровня).
- **Тесты:** `ConditionalNodeFilterTest` 24, `DocumentControllerApplyAnswersTest`
  19 (+ реальные DOCX XML/PDF text). `document.* + export.*` 251/2 — оба
  известные (BUG-061, stale MANAGER/SHARE).
- **Ревью APPROVE.** Follow-up: TASK-066 (вынести пайплайн из контроллера),
  BUG-064 (единый фильтр + `conditionalInline` в генераторе), BUG-065
  (`clauseId` vs `id`/`refId`), BUG-066 (текст `numberedClause` теряется),
  BUG-067 (400 вместо 500 на невалидное тело).
- **Урок:** фильтрация условий обязана быть рекурсивной и перепроверять
  развёрнутые дети; один общий «tree walker» не годится, если он применяет
  трансформер только к исходным детям.
