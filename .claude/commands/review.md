## Чеклист

### Архитектура
- [ ] Нет прямого импорта Repository из чужого модуля
- [ ] Контроллеры тонкие (только маппинг + сервис)
- [ ] DTO — records, с валидацией

### Качество кода
- [ ] Нет `any` в TypeScript
- [ ] Обработка ошибок везде (не `catch (Exception e)`)
- [ ] MongoDB-поля дат: `Instant` (не `OffsetDateTime`)
- [ ] jsonb-поля: `@JdbcTypeCode(SqlTypes.JSON)`

### Тесты
- [ ] Написаны тесты для нового кода
- [ ] Есть regression-тест для исправленного бага
- [ ] Если добавлен новый пользовательский сценарий — создана задача на E2E-тест в MCP tracker

### Состояние задачи в трекере
- [ ] Статус задачи в MCP соответствует реальному (`task_get { "id": "..." }`)
- [ ] Если у задачи есть `github_issue`: статус GitHub Issue соответствует статусу задачи
