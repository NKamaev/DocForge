# Промпт для генерации дизайна DocForge в open-design

Скопируй это содержимое и вставь в чат open-design.

---

Создай дизайн веб-приложения DocForge — конструктора документов.
Используй стек: React (визуально), shadcn/ui, Tailwind CSS (CDN).

## Дизайн-система (используй Tailwind классы с этими переменными):
- Бренд: oklch(0.55 0.16 232) (индиго)
- Основной текст: oklch(0.30 0.02 280)
- Вторичный текст: oklch(0.45 0.02 280)
- Фон: oklch(0.98 0.005 280)
- Поверхность (карточки): oklch(1 0 0)
- Границы: oklch(0.90 0.01 280)
- Шрифты: Inter Tight (UI), Source Serif 4 (документы), JetBrains Mono (код).

## Страницы (сгенерируй все):
1. **Главная**: Стат-карточки, список "Продолжить работу".
2. **Мои документы**: Дерево папок слева + таблица документов справа. Статусы: Черновик, Сформирован, Экспортирован.
3. **Шаблоны**: Пилл-табы (Все/Опубликованные/Черновики) + таблица.
4. **Конструктор шаблона**: Сверху тулбар TipTap (B, I, H1, H2, Table, ¶ для параметров), слева редактор с текстом договора и параметрами {{номер}}, справа панель параметров.
5. **Заполнение (Анкета)**: Сплит-лейаут. Слева — форма с полями (Номер, Город, Дата), справа — превью документа.

## Требования:
- Весь интерфейс на русском языке.
- Используй классы Tailwind: bg-surface, text-ink-2, border-border, rounded-lg.
- Кнопки: класс bg-brand для основных действий.
- Таблицы: w-full text-sm, hover:bg-brand-soft.
- Изображения: только серые заглушки.
- Мобильная версия: при 920px скрывать сайдбар.
- Оберни результат в `<artifact identifier="docforge-web" type="text/html">...</artifact>`
