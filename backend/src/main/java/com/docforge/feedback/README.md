# Модуль feedback

Обработка сообщений об ошибках от пользователей.

## Ответственность

- Приём и сохранение отчётов об ошибках
- API для отправки ошибок с фронтенда

## API

| Метод | Путь | Описание |
|-------|------|---------|
| POST | `/api/feedback` | Отправить отчёт об ошибке |

## Ключевые классы

| Класс | Описание |
|-------|---------|
| `FeedbackController` | REST-контроллер: приём сообщений об ошибках |
