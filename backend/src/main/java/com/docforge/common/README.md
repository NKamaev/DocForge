# Модуль common

Общие утилиты, исключения и форматтеры, используемые всеми модулями.

## Структура

### exception/

Глобальные исключения и обработчик ошибок.

| Класс | Описание |
|-------|---------|
| `GlobalExceptionHandler` | `@ControllerAdvice` — единый формат ошибок REST API |
| `ValidationException` | Ошибка валидации (400) |
| `NotFoundException` | Ресурс не найден (404) |
| `AccessDeniedException` | Нет доступа (403) |
| `ConflictException` | Конфликт (409) |

Формат ответа об ошибке:
```json
{ "error": "NOT_FOUND", "message": "Template not found", "details": {} }
```

### format/

Форматтеры для подстановки значений параметров в документ.

| Класс | Описание |
|-------|---------|
| `DateFormatter` | Дата → локализованная строка |
| `NumberFormatter` | Число →分组 строка |
| `FioFormatter` | ФИО → склонение (опционально) |

## Зависимости

Используется всеми модулями. Не имеет внешних зависимостей внутри проекта.
